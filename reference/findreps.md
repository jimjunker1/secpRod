# findreps

This function finds and sets breaks on repeated runs of similar
character types. It is used to parse the formula structure and variables
in \`massForm\` for converting lengths to mass in
[`convert_length_to_mass()`](https://jimjunker1.github.io/secpRod/reference/convert_length_to_mass.md).

## Usage

``` r
findreps(x, counter = NULL)
```

## Source

https://stackoverflow.com/questions/33155662/find-and-break-on-repeated-runs

- x:

  character string of the formula structure

- counter:

  stuff
